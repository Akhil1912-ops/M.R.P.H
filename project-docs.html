Hyderabad Metro Journey Planner

Multimodal route comparison — Taxi vs Taxi + Metro

What it does

Ever wondered whether to book a cab straight to your destination or take a taxi to the metro, ride the metro, then taxi again? This webpage answers that.

You enter your starting address and destination. The webpage compares direct taxi (door-to-door) with taxi + metro routes. It weighs travel time, distance, and how many metro transfers you’d need, then recommends the better option — with reasons.

Built for Hyderabad’s metro network, using real-time traffic data and official metro schedules.

How it works

1
Find nearby stations. It selects the 7 closest metro stations to your start and the 7 closest to your destination. More options help find the best route, not just the nearest station.
2
First mile & last mile. For each station, it figures out how you reach it — walk (if within 500m) or taxi. Same for the other end: from the arrival station to your destination. Times come from Google Directions, including traffic.
3
Build route combinations. It pairs every “from” station with every “to” station (7×7 = 49 combinations), adds metro travel time from a precomputed dataset, and works out total journey time for each.
4
Score & rank. Each route gets a convenience score from access distance (how far to/from stations), number of metro transfers, and metro segment length. Routes are sorted by this score.
5
Direct taxi check. Six rules decide when direct taxi wins: e.g. short distance, metro not saving enough time, or first/last mile too long. If any rule passes, direct taxi is recommended.
6
Return results. You get the top 5 taxi+metro routes plus the direct taxi option, with one highlighted as the recommendation.

Tech stack

Backend, APIs, and deployment:

Python 3.11 Flask Pandas Requests Google Maps API Places Autocomplete Directions API Gunicorn Render

Uses the Requests library to call Google Directions (taxi times with traffic) and Places Autocomplete for address search. Metro travel times are precomputed and stored in a CSV.

Project structure

  • app.py — Flask app; serves the main page and the route-finding API
  • station_finder.py — Core engine: finds nearest stations, computes taxi/walk legs, scores routes, decides when to recommend direct taxi
  • hyderabad_metro_stations.py — Metro data: Red/Blue/Green lines, 56 stations with coordinates, interchange info
  • station_pairs_with_times.csv — Precomputed metro travel times between station pairs (~3,000+ routes)
  • templates/index.html — Web UI: address inputs with autocomplete, route cards, recommendation display

When direct taxi wins

The app suggests a direct taxi (instead of metro) when at least one of these is true:

  • Door-to-door distance is 7 km or less
  • Taxi+metro takes at least 1.5× longer than direct taxi
  • Direct taxi saves you 20+ minutes compared to metro
  • First mile + last mile add up to 80% or more of the direct distance
  • Either first or last mile alone is 70%+ of the direct distance
  • You need 2+ metro transfers and taxi+metro is still 1.3× slower than direct taxi

Metro data

Uses official Hyderabad Metro data: Red, Blue, and Green lines; 56 stations; 3 interchange stations (Ameerpet, JBS Parade Ground, Mahatma Gandhi Bus Station). Metro travel times between station pairs are loaded from station_pairs_with_times.csv, so the app doesn’t have to compute them on every request.
